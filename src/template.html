Review your application with Claude Code

Claude Code reads your repository and reports what it finds for each concern. You check the evidence and decide. Nothing leaves this page: the prompt is built here and the findings are pasted back here.

  1. Choose what to review

  2. Run it in Claude Code

    Open your repository and start Claude Code in plan mode, which is read-only: run claude --permission-mode plan, or press Shift+Tab to cycle to plan mode, or type /plan. Then paste the prompt.

    Only run an agent on a repository you trust, or on a throwaway copy. A repository can contain text, hooks, settings or MCP servers that try to steer an agent. For code you do not trust, use a fresh checkout with project hooks, MCP servers and project settings turned off, and no credentials in the environment.

What’s included
What every concern includes




Review question
A question to put to the team for every concern, so reviews don’t depend on who remembers what.


Trade-off
The cost of each choice in plain terms, so decisions are made on purpose.


Ownership level
Each concern is marked own or guardrail, so it’s clear what the architect decides and what teams implement.


Agent-ready
An agent check level, search hints and a copy-ready Claude Code prompt for each concern.


Related concerns
Jump to the concerns that travel together, like retries, idempotency and timeouts.
