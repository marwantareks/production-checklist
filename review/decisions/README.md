# Decision records

One pair of files per review round: a triage (what the two reviewers found, merged into proposed edits, with a reason for each) and a decisions record (what the author accepted and why).

The records are the history of why the content and the agent prompt say what they say. When you change a concern, read the round that last touched it. Rule changes to the agent prompt are numbered P1 to P48 in these records and listed in `docs/REVIEW_PROCESS.md`.
